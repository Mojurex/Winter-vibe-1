🌐 Web сайт хэрхэн ажилладаг вэ?

📄

Файлуудын цуглуулга

Web сайт нь HTML, CSS, JavaScript файлуудаас тогтоно. Эдгээр файлууд сервер дээр байрладаг. Та сайтанд орохдоо браузер эдгээр файлуудыг сервер руу асуудаг.

Та сайт нээх үед сервер компьютер эдгээр файлуудыг таны компьютер, утасруу илгээдэг. Тэгэхэд браузер эдгээр файлуудыг унших болон сайтыг үзүүлдэг.

🔄

Хүсэлт, хариулт системэ

Та URL хаягийг оруулах үед браузер сервер руу "энэ сайтийн файлуудыг надад өгөөч" гэж асуудаг.

Сервер хариулдаг: "Болоо! Энд файлуудаа аваарай." Тэгэхэд браузер эдгээр файлуудыг цэгцэлэн та үзүүлэх гоёмсог сайтыг үзүүлэдэг. Энэ яг л та хүсэлт хүргүүлэх мэт юм!

✨ Frontend ойлголт

Frontend нь та үзэх болон ашигладаг хэсэг юм. Энэ нь гурван хэлээр үүсэж байна:

📝

HTML

HyperText Markup Language

Энэ нь байшингийн хүрээ зохиодог. Текст, дүрс, товчлуур бүтцийг үүсгэдэг.

<h1>Сайн байна уу!</h1>
<button>Асаалт</button>
🎨

CSS

Cascading Style Sheets

Энэ нь байшингийг өнгөлдөг. Өнгө, хэмжээ, байршлыг өөрчилдөг.

color: #FF69B4;
border-radius: 10px;
⚡

JavaScript

JS

Энэ нь байшингийг идэвхтэй болгодог. Товчлуур дээр дарах зэргийг хүлээн авдаг.

button.onclick = () => {
  alert('Санаа!');
};

🏠 Байшингийн жишээ:

HTML = Байшингийн хүрээ ✓

CSS = Өнгө, сувиваа ✓

JavaScript = Гэрлийн сөнөө, цуметүүр

Code нь компьютерийн хэл

Код бол компьютерт ямар нэгэ үйлдэл хийлэхийг заасан зааварчилгаа юм. Та Монгол хэлээр ярилцдаг мэт, компьютер код хэлээр ярилцана.

Энгийн жишээ:

if (та товчлуур дарав) {
  Сайн байна уу гэж хэлэх
}

Үнэмлэхүй жишээ:

<button>
  Намайг дарна уу!
</button>
