✨ Frontend гэж юу вэ?

Frontend бол чи вэб сайт дээр харж, дарж, ашиглаж байгаа бүх зүйл юм. Товч, зураг, текст, өнгө — бүгд Frontend! Энэ нь 3 үндсэн хэлтэй:

🧱

HTML

Хүрээ

HTML нь байшингийн хүрээ, суурь шиг. Текст, зураг, товчлуур хаана байрлахыг заана.

<h1>Сайн байна уу!</h1>
<button>Товчлуур</button>
🎨

CSS

Өнгө ба загвар

CSS нь байшинг буддаг, чимэглэдэг хэсэг. Өнгө, хэмжээ, хэлбэрийг гоё болгодог.

color: pink;
border-radius: 10px;
⚡

JavaScript

Үйлдэл

JavaScript нь байшинд гэрэл асаах, хаалга нээх шиг үйлдэл нэмдэг. Товч дарахад юу болохыг шийддэг.

button.onclick = () => {
  alert('Сайн уу!');
};

🏠 Байшингийн жишээ:

HTML = Байшингийн хүрээ

CSS = Өнгө, чимэглэл

JavaScript = Гэрэл, товч, хөдөлгөөн
