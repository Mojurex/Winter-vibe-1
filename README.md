# 🌈 Vibe Coding - Хүүхдүүдэд зориулсан сурах цэцэрлэг

## 📖 Сайтын тайлбар

Vibe Coding нь **дунд ангийн хүүхдүүдэд** вэб хөгжүүлэлт, интернет, кодын үндсийг сайхан, хөгжилтэй байдлаар үйлдэмжээ.

## 🎯 Суралцах сэдвүүд

1. **🌍 Интернет гэж юу вэ?** - Интернетийн үндсийн ойлголт
2. **🌐 Web сайт хэрхэн ажилладаг вэ?** - Web сайтын архитектур
3. **✨ Frontend ойлголт** - HTML, CSS, JavaScript-ийн үүрэг
4. **💻 Code гэж юу вэ?** - Кодын ойлголт
5. **🚀 Vibe Coding ойлголт** - AI-ийг ашигладаг код үүсгэх
6. **🌀 Prompt → Code → Website Урсгал** - Сөхөрүүлэлт, код, вэбсайтын хүрээ

## 🎨 Дизайн шинж чанар

- **Өнгөний сонголт**: Сул розовуу, найрсаг, хүүхэлдэхүүнд ээлтэй өнгө
- **Responsive Design**: Утас, таблет, компьютер дээр төгс ажилладаг
- **Анимейшон**: Fade-in, bounce, float, slide анимейшонууд
- **Интерактив Элементүүд**: 
  - Дэлгэрэнгүй товчлуур (reveal/hide)
  - Flow үүсгэгч (prompt → code → preview)
  - QR код
  - Hover эффектүүд

## 📱 Ашигладаг технологи

- **HTML5**: Semantic HTML зохиомж
- **CSS3**: Modern CSS, Flexbox, Grid, Animations
- **JavaScript**: Vanilla JS (frameworks үгүй)
- **QR Code API**: https://api.qrserver.com

## 🚀 Ашиглах аргаа

### 1. Файлууд нээх
Энгийнээ `index.html` файлыг браузерээр нээнэ үү.

```bash
# macOS дээр
open index.html

# эсвэл браузер дээр Drag & Drop хийнэ үү
```

### 2. Интернет сервер (хэрэв хэрэгтэй бол)
```bash
# Python 3 ашиглаж серверт дээлүүлэх
python -m http.server 8000

# дараа нь браузерээр нээнэ үү:
# http://localhost:8000
```

## ✨ Интерактив функцүүд

### Дэлгэрэнгүй товчлуур
- Картнууд дээрх "Дэлгэрэнгүй ▶" товчлуур дээр дарвал нэмэлт мэдээллийг үзүүлнэ

### Prompt → Code → Website
- Сүүлчийн "🌀 Prompt → Code → Website Урсгал" хэсэгт өөрөө туршиж үзээрэй:
  - Анхны текст оруулна (жишээ: "цэнхэр товчлуур", "розовуу товчлуур")
  - AI үүсгэх кодыг үзүүлнэ
  - Preview дээр үзүүлнэ

### QR Код
- Утсаараа QR кодыг скан хийгээд сайтад нүүрвэл мобайл хөрүүтэй байна

### Навигейшн
- Дээрх меню ашиглаж шинэ хэсэгт очнө
- Гөлгөр скролл эффект байна

## 📚 Сургалтын сэдвүүд

### 1. Интернет (Internet)
- Интернет нь компьютер, ухаалаг утас, таблетыг хоорондоо холбох сүлжээ
- Дэлхийнхүүс мэдээллийг илгээ, авах үйлдэл

### 2. Web сайт (Website)
- HTML, CSS, JavaScript файлуудын цуглуулга
- Хүсэлт → Хариулт системэ (request-response)
- Браузер файлуудыг татаж авч үзүүлдэг

### 3. Frontend
- **HTML**: Байшингийн хүрээ (structure)
- **CSS**: Өнгө, дүрслэл (styling)
- **JavaScript**: Интерактив үйл ажиллагаа (behavior)

### 4. Code
- Компьютерийн хэл
- Хэрэглэгчийн санаа → компьютерийн ойлголт
- If/else, loops, functions зэрэг үндсийн элементүүд

### 5. Vibe Coding
- AI ашигладаг шинэ технологи
- Санаа → AI ойлгоно → Автоматаар код үүсгэнэ
- Урьдчилан бичсэн code templates дээр байна

### 6. Prompt → Code → Website Flow
- Сэтгэл (prompt) бичнэ
- AI код үүсгэнэ
- Website дээр үзүүлнэ

## 🐛 Асуудал засах

### QR Код үзүүлэгдэхгүй байвал
- Интернет холболт шалгана уу
- API endpoint (api.qrserver.com) ашигладаг
- Offline горимд placeholder үзүүлнэ

### Анимейшонууд ажиллахгүй байвал
- Browser версион шинэ эсэх шалгана уу
- CSS animations дэмжүүлэлттэй браузер ашиглана уу

### JavaScript алдаа байвал
- Browser console нээж (F12) алдааг шалгана уу
- Network tab дээр файлууд ачаалагдсан эсэх шалгана уу
